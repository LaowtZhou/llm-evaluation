# 自然选择号 · VOXEL ODYSSEY

一张由 Three.js 驱动的沉浸式体素飞船展示页。船体会从程序化的环形居住区、中央舰脊和三台引擎体素化成 **4,000,000+ 个唯一占位单元**，并保留为压缩坐标/材质数据。占位单元以 0.045 世界单位网格写入空间场，内部遮挡面在建网格时剔除，GPU 只收到按材质分组的外露表面索引网格。宇宙背景是本地图片素材，星尘和远景碎片由场景实时绘制。

## 运行

页面以 ES module 加载 Three.js，需要联网获取固定版本的 Three.js 模块和可选字体。请通过本地 HTTP 服务打开，不要直接使用 `file://`：

```powershell
cd test-ChatGPT-6-Luna-natural-selection-voxel
python -m http.server 8000
```

随后访问 `http://localhost:8000`。若已安装 Node.js，也可用任意静态文件服务器提供当前目录。

## 操作

- 拖动旋转观察，滚轮缩放；触屏支持拖动和双指缩放。
- **视角**循环主视角、左舷、俯瞰和舰首视角。
- **暂停**冻结飞行姿态和推进器；**重置**恢复初始观测镜头。
- **沉浸**隐藏界面；全屏和环境音可独立开关。环境音需点击后才会启动。
- 快捷键：`Space` 暂停/继续、`V` 切换视角、`R` 重置、`I` 沉浸模式、`F` 全屏、`Esc` 退出沉浸模式。

窗口尺寸和设备像素比会限制渲染分辨率；窄屏减少星尘粒子数量。WebGL 不可用时保留宇宙背景并显示重试提示。
