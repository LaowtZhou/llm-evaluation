# EMBERFALL / 灰烬之冠

一个纯前端、无后端依赖的 Three.js WebGL 全屏 3D 体素火山战场：精灵军团在熔岩口迎战飞行恶龙，地形、遗迹、烟尘、火星与光影都由体素几何实时生成。

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端里显示的本地地址。

## 交互

- 鼠标左键拖拽：360°环绕旋转。
- 鼠标滚轮：拉近或拉远。
- 鼠标右键 / 中键拖拽：平移观察区域。
- 双击画布：回到默认镜头。
- 右下角圆形按钮：切换浏览器全屏。

## 结构

- `index.html`：全屏画布和极简交互入口。
- `styles.css`：全屏画布、氛围叠层与全屏按钮样式。
- `script.js`：Three.js 体素地形、精灵军团、主龙与远景龙、火山口、光照、阴影、粒子和 OrbitControls。

Three.js 通过 jsDelivr ESM 加载，首次打开页面需要网络连接；页面会在 WebGL 不可用时显示降级提示。
