# 大模型测评

这里集中保存大模型参与生成的软件与场景测试样例，便于按模型、任务和产物进行对照、复现与复查。

## 项目目录

- [3D体素场景测试](./3D体素场景测试/README.md)：对比不同模型在 Agent 工作流中完成体素场景理解、规划、生成和修正的表现。

## 3D体素场景测试包含什么

`3D体素场景测试` 下保留了以 `test-` 开头的原始测试目录。每个目录包含对应测试的页面、源码、资源、构建脚本或记录；不同测试的文件构成并不完全相同，请以各目录内的说明为准。

## 如何使用

1. 进入 [3D体素场景测试](./3D体素场景测试/README.md)，选择一个模型测试目录。
2. 阅读该目录中的 README、脚本或启动说明，再运行对应样例。
3. 对照产物和评估维度记录观察结果。请注明模型版本、提示词、Agent 工具链与运行环境，避免把环境差异误当成模型差异。

## 评估边界

仓库收录的是测试材料与产物，不代表已经完成统一基准测试，也不预先给出模型排名。不同目录可能使用不同提示词、工具、资源和完成标准；跨模型比较前应先统一任务条件并按共同量表复评。
